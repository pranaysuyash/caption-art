# Quick Start - Canvas Editor

## 🚀 Start Using It Now

### Step 1: Start Dev Server
```bash
cd frontend
npm run dev
```

### Step 2: Open Browser
Navigate to: **http://localhost:5173/agency/editor/demo**

### Step 3: Try It Out
1. **Choose an image** - Click a sample or upload your own
2. **Enter text** - Type in the text input field
3. **Select masking mode** - Try all 6 modes (if mask available)
4. **Customize style** - Use the right panel to adjust:
   - Font family, size, color
   - Letter spacing, line height
   - Outline, gradient, shadow
   - Rotation
5. **Export** - Click "Export" to download

---

## 📍 Access Points

### From Anywhere in the App
Click the **"Editor"** button in the header (top right, next to Settings)

### Direct URLs
- Demo: `http://localhost:5173/agency/editor/demo`
- Editor: `http://localhost:5173/agency/editor`

## 🎨 Features Available

### Masking Modes
- Full Behind
- Weave Through
- Horizontal Split
- Vertical Split
- Character by Character
- Partial Overlap

### Text Controls
- Font family, size, color, weight, style
- Letter spacing, line height
- Outline (width, color)
- Gradient (linear/radial, angle)
- Rotation (precise degrees)
- Font pairing suggestions
- Professional presets
- Custom preset saving
